# Велес Групп

Самостоятельный статический сайт строительной компании: HTML, CSS, JavaScript и локальные
изображения. Главная страница, каталог и карточки проектов работают без внешнего конструктора.

- `index.html` — главная страница;
- `catalog.html` — каталог проектов;
- `project.html?project=vg-01` — отдельная страница проекта.

Сайт подготовлен для публикации через GitHub Pages.
